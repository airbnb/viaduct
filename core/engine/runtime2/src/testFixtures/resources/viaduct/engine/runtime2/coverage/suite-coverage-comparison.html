Interaction obligations

The RFC-271 interactions first, then candidate interactions. Each count is the number of distinct test cases with evidence of that interaction; the evidence column says what counts as evidence. "n/a" means that side's generator config cannot produce the evidence (for example, no variable bindings), so zero is a property of the config rather than a coverage gap. "Not exercised" means the config could produce it but no case did.

Cases per resolver attribute

Distinct test cases with an invoked resolver showing each attribute, grouped by category. Attributes neither candidate produced are listed underneath.

Obligation and resolver-attribute combinations

Each row is the set of obligations and resolver attributes observed together in a case. Counts show cases on each side; this matrix is descriptive and does not affect D0 batch ranking.
